# U2K

个人 Linux 系统编程练习：通过 `open/read/write` 系统调用，学习用户态程序与内核交互的基本流程。

## 功能区别

| 功能 | `u2k.c` 基础版 | `u2k_par.c` 参数版 |
| --- | --- | --- |
| 文件路径 | 固定读取 `/proc/version` | 从命令行参数指定文件 |
| 读取方式 | 只读一次，最多 512 字节 | 每次读取最多 512 字节，循环到文件末尾 |
| 输出方式 | 只写一次，未处理部分写入 | 循环补写剩余数据，写入无进展时报告错误 |

参数版从“读取固定文件的一段内容”扩展为“按路径读取文件，并循环输出读取到的数据”。

## 使用

在 Linux 环境下编译和运行：

- 基础版：`gcc -Wall -Wextra u2k.c -o u2k`，运行 `./u2k`。
- 参数版：`gcc -Wall -Wextra u2k_par.c -o u2k_par`，运行 `./u2k_par /proc/version`。
